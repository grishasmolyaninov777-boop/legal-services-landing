# VIP Detailing Landing

Премиальный анимированный лендинг для VIP Detailing в Москве.

## Деплой

Production: https://legal-services-landing-sigma.vercel.app

## Что внутри

- статический one-page сайт без сборки;
- full-bleed секции на основе VIP-ассетов;
- адаптивная навигация, формы записи, модальное окно;
- scroll reveal, parallax, magnetic hover, tilt-карточки и плавающие CTA;
- проверка на Vercel production.

## Файлы

- `index.html` - структура лендинга и SEO;
- `styles.css` - визуальный слой, адаптив и анимации;
- `script.js` - интерактивность, формы, счетчики и эффекты;
- `vip-assets/` - изображения для секций.
